- Application purpose:The purpose of my Western Mountain & Wilderness Explorer application is to help users explore, search, and compare information about mountains, forests, and natural landscapes throughout the western United States. The program will allow users to filter destinations by state or region, compare mountain elevations, and save their favorite locations for future reference.

## How to Run the Application

My application will be developed using Python 3 and run through PyCharm. Once the program is complete, users will open the project in PyCharm, ensure a Python interpreter is configured, and run western_wilderness_explorer.py file. The program uses information stored in the data folder, so the required CSV files must remain within the project. When the application starts, a menu will appear, allowing users to choose which features they want to access.

## Major Features

My Western Mountain & Wilderness Explorer application will include approximately eight functions that allow users to interact with information about western landscapes. These planned features include displaying the main menu, loading destination information, viewing available destinations, searching for mountains or forests, filtering locations by state or region, comparing mountain elevations, saving favorite destinations, and viewing previously saved locations. Users will be able to navigate through the menu and return to it until they decide to exit the application.

## Python Concepts Used

My program will use Python concepts I learned in IS 3020, including variables, strings, integers, lists, dictionaries, conditional statements, while loops, for loops, functions, and user input. Lists and dictionaries will help organize destination information, while conditionals and loops will control how users navigate and interact with the application. I also plan to use CSV file handling to save and retrieve destination information, along with input validation and try/except statements to handle common errors.

## Data Files

I plan to use two CSV files within the data folder. The first file, destinations.csv, will contain information about each destination, including its name, state, geographic region, landscape type, elevation (in feet, when applicable), and a short description. The second file, favorites.csv, will store the destinations users choose to save for future reference. The program will read the destination information when it starts and retrieve saved favorites when requested.
